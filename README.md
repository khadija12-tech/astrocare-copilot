Offline health copilot for astronauts on deep-space missions. It learns each astronaut's **personal baseline**, detects drift early,
**explains** every alert, recommends actions, tracks **crew dynamics**, analyses **voice** stress, projects a **30-day digital twin**,
and prepares a **compressed packet for Earth** when communication is delayed. Decision support only, not a medical diagnosis.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py          # main app (works offline, SQLite storage)
python export_web.py          # regenerate vr/data.js and mobile/data.js
```
- `vr/index.html`: WebXR habitat (A-Frame). Open in a browser, or on a headset/phone. Host the folder on GitHub Pages.
- `mobile/`: offline-capable PWA (30-second check-in). Host over HTTPS, then "Add to home screen".

## Self-check (core of the challenge)
Blood pressure, glucose and temperature are also in the drift engine (two-sided warnings for glucose and temperature) and the scores.
Tab 'Self-check': blood pressure, heart rate, glucose, temperature, sleep, mood -> colour status, guidance, escalation, history charts. Ranges in `core/selfcheck.py` are general adult values: have a clinician review them before any real use.

## NASA risks coverage
The NASA evidence tab maps 17 HRP human-system risks to the app (6 covered, 6 partly, 5 out of scope).

## Structure
Five health areas follow NASA's five hazards (see the NASA evidence tab): cardio and bone/muscle (gravity), immunity/sleep (closed environment), mental/social (isolation), radiation, plus delay mode (distance from Earth).

`core/` simulator, analysis (z-score drift + Isolation Forest), explanations, recommendations (feedback loop), projection, crew, voice, delay, db.

## Limits
Illustrative rules and thresholds, simulated data (fixed demo seed 23), not clinically validated, needs flight-surgeon review.
Across 30 simulated seeds about 3% of healthy-crew system-days were flagged amber or red (false alarms).
